# IBM Design Thinking and IBM Loop

## IBM Design Thinking pillars
1. **Focus on user outcomes:** Define success in terms of users being able to locate and reserve books quickly, rather than simply completing a technical feature.
2. **Restless reinvention:** Continue improving the product based on real usage, feedback, and operational metrics.
3. **Diverse empowered teams:** Encourage collaboration among product, UX, engineering, QA, database, and DevOps contributors.

## IBM Loop: Observe → Reflect → Make
- **Observe:** Study user interactions, logs, and operational friction.
- **Reflect:** Analyze evidence, compare it with desired outcomes, and reconsider priorities.
- **Make:** Update the design, implement improvements, and validate the result.

## Example loop
Observe that users cannot easily identify available copies → reflect on search and inventory display → make a clearer availability indicator → test whether users find the right book faster.

Use real feedback and measurements when reporting actual outcomes.
