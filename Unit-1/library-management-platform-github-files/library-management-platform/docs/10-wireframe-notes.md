# Low-Fidelity Wireframe Notes

These notes describe proposed screens; they are not screenshots of a completed UI.

## Login
- Institution/library logo and platform name
- Username/email and password fields
- Sign-in action and clear validation messages
- Role-appropriate landing page after authentication

## Book Search Portal
- Search field with title, author, ISBN, and category support
- Search results with title, author, shelf location, and availability
- Clear no-results state
- Optional reserve action in a later iteration

## Librarian Checkout Dashboard
- Member lookup
- Book lookup / barcode input area
- Issue and return actions
- Due date and fine information
- Confirmation and error messages

## Admin Analytics Panel
- Total books and available copies
- Active loans and overdue count
- Fine summary
- Filters and report export in a later iteration

## Usability test tasks
Ask a participant to find a book, check availability, issue/return a book (in a prototype), and locate the overdue summary. Record completion, errors, questions, and suggestions.
