# SDLC and Quality Plan

## Lifecycle
1. Requirement gathering and domain analysis
2. Design thinking and UX wireframing
3. System architecture and database schema
4. Implementation
5. Automated CI/CD and testing
6. Deployment, observability, and continuous feedback

## Quality activities
- Unit tests for catalog and circulation rules
- API tests for valid and invalid requests
- Data-integrity checks for unique ISBN and valid loans
- Security review for authentication and role permissions
- Performance testing against the stated search response target
- User acceptance testing with students and library staff

## Continuous improvement
Collect feedback and operational metrics after each increment. Use findings to refine requirements and prioritize the next iteration.
