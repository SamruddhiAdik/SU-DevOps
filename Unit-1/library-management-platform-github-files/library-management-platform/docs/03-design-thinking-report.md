# Design Thinking Report

Design Thinking is a human-centered, iterative approach. The five stages below follow the assignment's structure.

## 1. Empathize
Study students, faculty, librarians, and administrators in their normal library workflows. Observe how they search for books, check availability, borrow and return items, and prepare reports.

## 2. Define
Core problem: library members experience delays locating, reserving, borrowing, and returning resources because of inefficient manual tracking, while staff lack centralized visibility and reliable reporting.

## 3. Ideate
Potential ideas include:
- Multi-field catalog search
- Book availability status
- Automated due-date reminders
- Dynamic QR membership cards
- Barcode-based issue and return
- Live inventory dashboards
- Automated fine calculation

## 4. Prototype
Create low-fidelity wireframes for:
- Login page
- User book-search portal
- Librarian checkout dashboard
- Administrator analytics panel

## 5. Test
Demonstrate prototypes to students and library staff. Ask users to complete search, issue, return, and reporting tasks. Record confusion, task completion time, and requested changes before implementing the next iteration.

## Iteration principle
Use test feedback to revise the design. The repository's starter API is not evidence that user testing has already occurred; add real test observations when available.
