# Terraform Infrastructure Starter

The assignment roadmap identifies Terraform for infrastructure automation. This folder is a placeholder for environment-specific resources.

Before adding resources:
1. Choose a cloud provider and region.
2. Define variables and outputs.
3. Configure remote state and locking.
4. Avoid committing credentials or secrets.
5. Review cost, network exposure, and least-privilege IAM.
6. Run `terraform fmt` and `terraform validate` before planning.

No cloud resources are created by this repository as provided.
